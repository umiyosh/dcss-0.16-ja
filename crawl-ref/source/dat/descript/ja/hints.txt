welcome

<white>ダンジョンクロウルへようこそ！</white>

あなたの目的は、<w>{{ return you.race() }} {{ return you.class()
}}</w>をダンジョンの深奥へ無事に導き、伝説のゾットのオーブを手にして
地上へ持ち帰ることです。とはいえ、最初は発見することを目標にしましょう。
できる限り深く潜ってみてください。ただし、死は至る所に潜んでいます。

今は、次のキーと機能だけを覚えてください。
  <input>$cmd[CMD_DISPLAY_COMMANDS]?</input> — アイテムとコマンドを表示します
  <input>$cmd[CMD_SAVE_GAME]</input>  — ゲームを保存し、後から再開できます
（ただし、一度死ぬと生き返ることはできません）
  <input>$cmd[CMD_LOOK_AROUND]</input>  — 周囲にあるものを調べます

ヒントモードでは、文書を読まなくてもCrawlの遊び方を学べます。
まだならチュートリアルを試してみてもよいでしょう。さらに詳しく知りたければ、
docs/ディレクトリにある次の文書も参照できます（ゲーム内でも読めます）。
  <lightblue>quickstart.txt</lightblue>     — Crawlのごく短い手引きです。
  <lightblue>crawl_manual.txt</lightblue>   — 種族、魔法、スキルなどの
詳細をすべて説明しています。
  <lightblue>options_guide.txt</lightblue>  — Crawlの操作画面は幅広く
変更できます。この文書ではすべての設定項目を説明しています。

それでは、よき探索を！

finished stashes

<input>$cmd[CMD_SEARCH_STASHES]</input>コマンドを使うと、ダンジョン内にある
すべてのアイテムを検索できます。たとえば、
<input>$cmd[CMD_SEARCH_STASHES]</input> <w>“dagger”</w>と入力すると、
すべてのダガーが一覧表示され、いずれかの場所まで移動できます。
<w>“shop”</w>や<w>“altar”</w>といった言葉を入力することもできます。

finished random 0

ゲームはキャラクターの冒険記録を自動で残します。
<input>$cmd[CMD_DISPLAY_COMMANDS]:</input>で記録を読み、
<input>$cmd[CMD_MAKE_NOTE]</input>コマンドで自分の記録も追加できます。
キャラクターが死ぬと、<w>morgue/</w>ディレクトリに二つのmorgueファイルが
残されます。.txtで終わるファイルには冒険記録の写しが含まれます。
プレイ中は<input>$cmd[CMD_CHARACTER_DUMP]</input>でダンプファイルを作成できます。

Crawlにはマクロ機能があります。<input>~m</input>を押し、まず起動キー

<tiles>アイテムを<input>right-click</input>して調べると</tiles><console>
