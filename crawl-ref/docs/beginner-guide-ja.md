# Dungeon Crawl Stone Soup 0.16-ja

## Mac版・初心者向け操作ガイド

このガイドは、DCSS 0.16-ja の標準キーバインドを前提に、
最初のプレイに必要な操作をまとめたものです。
ゲーム内の `?` では全コマンドを確認できますが、まずはここにある操作だけで遊べます。

## 最初に知っておくこと

DCSS はターン制です。こちらが操作しない限り、敵も行動しません。
危険な場面ではキーを連打せず、画面とメッセージを確認してください。

死亡したキャラクターは復活できません。`S` は死亡前へ戻るためのセーブではなく、
ゲームを中断し、あとから再開するためのコマンドです。

### Macでのキー表記

- `Ctrl-P` は Command キーではなく、Control キーを押しながら `P`
- `X` は Shift キーを押しながら `x`
- `>` は `Shift + .`
- `<` は `Shift + ,`
- 操作中は日本語入力をオフにして英字入力モードにする
- 操作を取り消すときは `Esc`

## 最低限覚える操作

| キー | 操作 |
| --- | --- |
| `方向キー` / `h j k l y u b n` | 移動。敵のいる方向へ進むと近接攻撃 |
| `o` | 未探索区域を自動探索 |
| `Tab` | 最も近い敵へ移動・攻撃 |
| `5` | HP・MPが回復するまで休息 |
| `.` | その場で1ターン待つ |
| `,` / `g` | 足元のアイテムを拾う |
| `i` | 所持品を見る |
| `q` | 薬を飲む |
| `r` | 巻物を読む |
| `>` | 階段を下りる |
| `<` | 階段を上る |
| `x` | 周囲を調べる |
| `X` | 現在の階の地図を見る |
| `S` | 保存して終了 |
| `?` | ヘルプ |
| `Esc` | 操作を取り消す |

## 移動

Mac のキーボードにはテンキーがないことが多いため、方向キーのほかに
次の vi キーを使えるようになると快適です。

```text
y  k  u
 ＼ ↑ ／
h ← ・ → l
 ／ ↓ ＼
b  j  n
```

| キー | 方向 |
| --- | --- |
| `k` | 上 |
| `j` | 下 |
| `h` | 左 |
| `l` | 右 |
| `y` | 左上 |
| `u` | 右上 |
| `b` | 左下 |
| `n` | 右下 |

大文字の方向キー（`K`、`L` など）は、敵や障害物を見つけるまで連続移動します。

タイル版ではマップをクリックして移動できます。敵が見えていなければ目的地まで自動移動し、
敵が見えている場合は1マスだけ移動します。敵・アイテム・地形を右クリックすると説明を確認できます。

## 基本の進め方

### 1. `o` で探索する

敵がいないときは `o` で未探索区域を自動探索します。
敵や重要なものを見つけると自動的に停止します。

### 2. 知らない敵を調べる

知らない敵を見つけたら、すぐに攻撃せず次のどちらかで確認します。

- 敵を右クリックする
- `x` を押し、カーソルを敵へ移動する

見慣れない固有名の敵や、危険を示す色で表示された敵には特に注意してください。

### 3. 敵を1体ずつ戦う

敵の方向へ移動すると近接攻撃します。`Tab` でも近くの敵へ移動・攻撃できますが、
連打は危険です。新しい敵が現れたときや HP が減ったときは操作を止めてください。

### 4. 戦闘後に `5` で休む

周囲に敵がいないことを確認して `5` を押し、HP と MP を回復します。

```text
敵を倒す
  ↓
周囲の安全を確認する
  ↓
5 で回復する
  ↓
o で探索を再開する
```

### 5. 階段を使う

階段の上で `>` を押すと下の階へ、`<` を押すと上の階へ移動します。
危険な階へ来てしまった場合は、無理に探索せず前の階へ戻ることもできます。

## 生き残るための基本

### 複数の敵と同時に戦わない

開けた場所で囲まれそうになったら、狭い通路へ後退して1体ずつ戦います。

```text
悪い位置              良い位置

敵 敵 敵              壁 壁 壁
  自分                敵 自分 壁
敵 敵                 壁 壁 壁
```

### 早めに逃げる

次のような場面では、攻撃を続けず通路や階段へ退却してください。

- HP が半分近くまで減った
- 新しい敵が追加で現れた
- 強さの分からない敵がいる
- 毒や混乱などの状態異常になった
- 逃げ道を塞がれそうになった

### 消耗品を惜しまない

危険を感じた段階で所持品を確認します。HP がほとんど残っていない状態まで待つと、
回復しても逃げ切れないことがあります。

| キー | 使用するもの |
| --- | --- |
| `q` | 薬 |
| `r` | 巻物 |
| `V` | ワンドなどの発動アイテム |
| `a` | 種族・信仰などの特殊能力 |
| `z` | 習得済みの魔法 |

## アイテム

### 拾う・確認する

| キー | 操作 |
| --- | --- |
| `,` / `g` | 足元のアイテムを拾う |
| `i` | 所持品を見る |
| `d` | アイテムを床へ置く |
| `Ctrl-F` | 発見済みのアイテムや施設を検索する |

`i` で所持品を開き、アイテムに割り当てられた英字を押すと説明を確認できます。

### 装備

| キー | 操作 |
| --- | --- |
| `w` | 武器を装備する |
| `'` | 装備中の武器を切り替える |
| `W` | 防具を装備する |
| `T` | 防具を外す |
| `P` | 指輪・護符を装備する |
| `R` | 指輪・護符を外す |

大文字と小文字は別のコマンドです。たとえば `w` は武器、`W` は防具の装備です。

### 消耗品・道具

| キー | 操作 |
| --- | --- |
| `q` | 薬を飲む |
| `r` | 巻物を読む |
| `V` | ワンドなどを使う |
| `f` | 準備済みの矢・投擲物を発射する |
| `Q` | 発射するアイテムを指定する |

### 食事

DCSS 0.16 には空腹の概念があります。

| キー | 操作 |
| --- | --- |
| `e` | 食べ物を食べる |
| `c` | 死体を解体して肉にする |

空腹を知らせるメッセージが表示されたら、`e` で食料を確認してください。

## 魔法・能力・情報

近接戦闘キャラクターで始める場合、最初からすべて覚える必要はありません。

| キー | 操作 |
| --- | --- |
| `z` | 魔法を唱える |
| `I` | 習得済みの魔法を見る |
| `M` | 魔法書から魔法を習得する |
| `a` | 特殊能力を使う |
| `m` | スキルを見る |
| `^` | 信仰している神の情報を見る |
| `@` | キャラクターの状態を見る |
| `%` | 属性耐性を見る |
| `\` | 判明しているアイテムを見る |
| `Ctrl-P` | 過去のメッセージを読み返す |

魔法や能力を選んだあとは、画面の指示に従って対象を指定します。
操作を中止するときは `Esc` を押します。

## 地図と自動移動

| キー | 操作 |
| --- | --- |
| `o` | 現在の階を自動探索する |
| `X` | 現在の階の地図を見る |
| `G` | 別の階層へ自動移動する |
| `Ctrl-F` | アイテムや施設を検索して移動する |
| `<` | 上の階へ移動する |
| `>` | 下の階へ移動する |

## 保存と終了

| キー | 操作 |
| --- | --- |
| `S` | 確認後、保存して終了する |
| `Ctrl-S` | 確認せず、すぐに保存して終了する |
| `Ctrl-Q` | キャラクターを死亡させ、ゲームを放棄する |

通常は `S` を使ってください。`Ctrl-Q` は一般的なアプリの終了操作ではなく、
現在のキャラクターを意図的に死亡させるコマンドです。
macOS の `Command-Q` ではなく、ゲーム内の `S` を使うのが安全です。
